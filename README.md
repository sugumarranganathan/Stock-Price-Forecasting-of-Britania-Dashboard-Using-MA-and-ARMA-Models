# 📈 Stock Price Forecasting of Britannia Using MA and ARMA Models

## 📌 Overview
This project forecasts Britannia Industries stock prices using Time Series Analysis techniques. Moving Average (MA) and AutoRegressive Moving Average (ARMA) models are used to analyze historical stock data and predict future prices.

## 🎯 Objectives
- Analyze historical stock prices
- Perform stationarity testing using ADF Test
- Build MA and ARMA models
- Forecast future stock prices
- Compare model performance using RMSE

## 📊 Dataset
- Stock: Britannia Industries Ltd.
- Features: Date, Open, High, Low, Close, Volume

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Scikit-Learn
- Streamlit

## 🔄 Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. ADF Stationarity Test
5. Differencing
6. MA Model Development
7. ARMA Model Development
8. Forecasting
9. RMSE Evaluation
10. Model Comparison

|---------|---------|
